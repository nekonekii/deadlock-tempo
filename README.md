# Deadlock Tempo

Внешний оверлей для Windows: часы матча считываются с экрана, а напоминания о событиях появляются сверху по центру с игровыми картинками. Текущая версия приложения — **1.13.3**.

## Установка с автозапуском

Нужны Windows 10/11, .NET Framework 4.8 и доступный компонент Windows OCR. Компилятор берётся из установленного .NET Framework; Visual Studio, Python и Node.js не нужны. Для клонирования нужен Git; можно также скачать ZIP репозитория и распаковать его.

Откройте обычный PowerShell под своим пользователем:

```powershell
git clone https://github.com/nekonekii/deadlock-tempo.git
cd deadlock-tempo
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

`ExecutionPolicy Bypass` применяется только к этому запуску PowerShell и не меняет постоянную политику системы.

Установщик собирает приложение, запускает проверки и устанавливает его в `%LOCALAPPDATA%\DeadlockTempo\App`. При повторной установке находит существующую установку через её задачу Windows, сохраняет настройки и расписание, делает резервную копию файлов.

Затем включает задачу **DeadlockTempo Watcher**: она запускается при входе в Windows и проверяется раз в минуту. Помощник раз в две секунды проверяет, запущен ли Deadlock, и открывает оверлей автоматически. Если игра уже запущена, оверлей запускается без ожидания нового матча. После закрытия игры помощник продолжает ждать следующего запуска.

Запускайте Deadlock обычным способом из Steam. Изменять параметры запуска игры не нужно. Маленькая строка **TEMPO** справа сверху показывает состояние; крупные уведомления появляются только около нужного времени. Для OCR окно игры должно быть видимо и активно. Если часы не распознаются, проверьте английский компонент OCR в языковых настройках Windows.

Готовый промпт для установки через Codex или другого помощника — [INSTALL_PROMPT.md](INSTALL_PROMPT.md).

## Оформление и события

- Крупный текст сверху по центру, игровая картинка и повторяющиеся световые контуры; текст не масштабируется в ходе анимации.
- Жёлтое предупреждение за 30 секунд, красное за 10 секунд, подтверждение ещё на 10 секунд.
- Размер по умолчанию — 48 px для высоты 1440 px, отступ сверху — 17%; размеры адаптируются к окну игры.
- Одновременные события показываются отдельными строками, включая чашу, руны и напоминание о разломе.

| Событие | Расписание в текущем профиле |
| --- | --- |
| Малые лагеря | Первое появление в 02:00 |
| Коробки и контейнеры баффов | Первое появление в 03:00 |
| Средние лагеря | Первое появление в 05:00 |
| Руны | С 05:00 каждые 5 минут |
| Крупные лагеря | Первое появление в 08:00 |
| Автоматы | Первое появление в 08:00 |
| Чаша душ | С 10:00 каждые 5 минут |
| Нестабильный разлом | Первое примерное окно 11:00–13:00; с 18:00 каждые 7 минут — напоминание проверить карту |

Разлом **не определяется точно**: повторы — напоминания, а не подтверждения появления. Подбор чаши и зачистка лагерей не отслеживаются. Тайминги и источники хранятся в [профиле](outputs/DeadlockTempo/source/profile.json); проверка публикаций для чаши и разлома была выполнена 20 октября 2026 года. Расписание не обновляется из интернета автоматически.

## Управление

- `Ctrl + Alt + F10` — панель управления и настройки.
- `Ctrl + Alt + F9` — показать/скрыть таймеры.
- `Ctrl + Alt + F8` — ручной старт/пауза; отключает автоматическую синхронизацию.
- Закрытие панели крестиком оставляет приложение в трее.
- Для отключения автозапуска используйте настройки или пункт «Выход и отключить автозапуск» в трее.

Шрифты Valve Pulp / Oracle читаются из стандартной установки Deadlock в `Program Files (x86)\Steam`; при их отсутствии используются Georgia / Segoe UI. Шрифты игры в репозиторий не включены.

## Обновление и проверка

```powershell
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Для сборки без установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\outputs\DeadlockTempo\source\build.ps1
```

Приложение поддерживает `--test <полный-путь-к-отчёту>` для проверки логики и `--status-smoke-test <полный-путь-к-отчёту>` для проверки интерфейса вне экрана. GUI-приложение следует запускать с `Start-Process -Wait`, чтобы дождаться отчёта. Установщик автоматически запускает первую проверку. На момент публикации проходят 145 проверок логики и проверка WPF-интерфейса.

Для изолированной проверки установщика есть `-InstallRoot <папка> -NoAutoStart`. В этом режиме не регистрируется новый автозапуск. Не указывайте папку рабочей установки, если не хотите её обновлять.

## Данные и исходники

Приложение использует отдельные окна Windows, без внедрения DLL, драйверов и чтения памяти игры. Кадры обрабатываются локально; обычная работа не сохраняет их и не отправляет в сеть. Приложение не скрывается от античита, и гарантии его реакции нет.

В папке данных находятся `settings.json`, `profile.json` и `autostart.log`. Файл `data-directory.txt` рядом с установленным EXE связывает приложение и задачу Windows с одной папкой данных. Эти локальные данные и диагностические записи не включены в репозиторий.

Исходники: [outputs/DeadlockTempo/source](outputs/DeadlockTempo/source). Подробности приложения: [README.txt](outputs/DeadlockTempo/README.txt).

Игровые изображения принадлежат их правообладателям; это не оригинальная графика Tempo. Происхождение изображений указано в [SOURCES.txt](outputs/DeadlockTempo/source/icons/SOURCES.txt). Проект не является официальным продуктом Valve.
